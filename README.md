> A feature-rich notes manager built with TypeScript — create, tag, search, and organize notes with a clean, fast interface.

---

## ✨ Features

- 🗒️ **Create & Edit Notes** — Rich text notes with instant save
- 🏷️ **Tagging System** — Organize notes with custom tags
- 🔍 **Search** — Full-text search across all notes
- 📂 **Organize** — Sort and filter by date, tag, or title
- 🌙 **Dark Mode** — Eye-friendly dark theme
- 💾 **Persistent Storage** — Notes saved locally
- 📱 **Responsive Design** — Works on all screen sizes

| Layer | Technology |

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- TypeScript (`npm install -g typescript`)

### Installation

```bash
# Clone the repository
git clone https://github.com/Matam-Rohith/notes-app.git

cd notes-app

# Install dependencies
npm install

# Compile TypeScript
tsc

# Open in browser
open index.html
```
